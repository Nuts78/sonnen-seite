# Sonnen-Seite

Home-Assistant-App, die eine einzige, öffentliche Seite mit einer lachenden oder traurigen Sonne ausliefert:
kommt der Strom gerade von der PV-Anlage oder vom Netz? Nur lesend, ohne Zugriff auf Home Assistant.

Installation: In Home Assistant unter Einstellungen → Apps → App-Store → ⋮ → Repositories
`https://github.com/Nuts78/sonnen-seite` hinzufügen und „Sonnen-Seite“ installieren.
